# Locadora

## Descrição
Este projeto é uma aplicação que simula um sistema de locação de veiculos com o intuito de utilizar os conceitos de arquitetura de software aprendidos na disciplina Engenharia de Software 1

## Conceitos abordados
- Model
- View
- Controller
- Presenter
- DAO
- DTO
- Mapper
- Repository
- Factory
- Builder

## Funcionalidades
- Cadastro e mantenimento de Clientes.
- Cadastro e mantenimento de Veiculos.
- Cadastro e listagem de Locacoes.

## Tecnologias Utilizadas
- **Java 17**
- **SQLite**

## Como testar?
Executar em uma IDE compatível com Java e utilizar o terminal como menu da aplicação
